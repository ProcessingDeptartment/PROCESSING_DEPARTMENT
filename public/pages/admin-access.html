User Page Access

Administrator — control which categories each role can see, and whether they can view only or also edit

⛔ Administrator access required.

Default behaviour: All non-administrator roles can only see Records and Verifications until they enter their own passkey. Once they do, they see whatever pages you configure below. When restrictions are OFF for a role, the role sees everything it is normally allowed to see after unlocking.
Hidden — not shown to this role
View only — can see but not save changes
Edit — full access

Changes require your administrator passkey to save.
