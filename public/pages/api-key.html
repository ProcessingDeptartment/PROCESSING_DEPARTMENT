The key is stored on this device only and is sent with every request to the records database. Enter it once per device (per browser). Ask the system administrator for it.

What this protects, and what it doesn't. This stops the records database being read or wiped by anyone who simply has its address. It does not identify who you are: it's one shared key for the whole facility, and anyone who can already use this site can read it out of their own browser. Per-person identity and role enforcement need Entra ID login, which isn't built yet — so this is a lock on the front door, not an audit trail of who did what.
